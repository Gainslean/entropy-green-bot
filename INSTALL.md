# Entropy GREEN — установка и запуск

Торговый бот для спреда между двумя биржами HIP-3 на Hyperliquid (рынки NBIS, DRAM, EWY, SNDK).
Режим **GREEN**: позиция закрывается только с прибылью; если прибыль не пришла, позиция
закрывается через 10 часов. Программа поставляется в скомпилированном виде (без исходного кода),
настраивается сама и обновляется кнопкой «Обновить» в панели.

> Торговля связана с риском потерь. Бот ставит реальные ордера только после того, как вы явно
> включите торговлю (раздел 6). До этого он лишь проверяет настройки.

## 1. Что нужно

- Сервер **Linux**: Ubuntu 22.04 / 24.04 или Debian 12, 2 ядра, 2–4 ГБ памяти, 10 ГБ диска,
  архитектура та, для которой собран архив (обычно x86-64).
  Лучше всего в Токио (там серверы Hyperliquid) — например AWS ap-northeast-1, Vultr Tokyo.
- Доступ к серверу по SSH с правами sudo.
- От 1 до 9 кошельков Hyperliquid с USDC. Рекомендуется от ~$100–150 на кошелёк.

Больше ничего знать не нужно: номер ПК, секунды входа и рынки программа получает сама.

## 2. Подготовка кошельков (на каждом кошельке)

1. Откройте https://app.hyperliquid.xyz/API, подключите кошелёк.
2. Создайте **API Wallet** (агента), сохраните его **приватный ключ агента** и нажмите «Authorize».
3. Пополните кошелёк USDC.

Боту нужны только **адрес основного кошелька** и **приватный ключ агента**.
Главный приватный ключ (seed-фразу) кошелька **никому и никуда не вводите**.

## 3. Загрузка архива на сервер

С компьютера:
```bash
scp entropy-green-*.tar.gz user@IP_СЕРВЕРА:~
```
На сервере:
```bash
tar xzf entropy-green-*.tar.gz
cd entropy-green-*/
```

## 4. Установка (одна команда)

```bash
sudo bash install-green.sh
```
Скрипт спросит только кошельки: сколько их и для каждого — адрес и ключ агента (ключ вводится
скрыто, сохраняется только в `/opt/entropy-green/.env` с правами 600 и никуда не отправляется).
Всё остальное он делает сам:
- установит нужное (curl, jq, openssl, синхронизацию времени; Python не нужен) и проверит архив
  и программу — без сети и без ключей;
- зарегистрирует этот ПК у сервера настроек владельца бота и получит **номер ПК и секунды входа**
  (если сервер недоступен, ПК работает в резервных секундах и сам повторит регистрацию позже);
- запишет настройки: все четыре рынка, оба направления, секунды этого ПК;
- проверит кошельки и настройки — **без ордеров**;
- запустит **панель по ссылке с паролем** и в конце напечатает:

```
Панель этого ПК — откройте в браузере на своём компьютере:
  Ссылка:  https://IP_СЕРВЕРА:8443
  Логин:   admin
  Пароль:  (20 букв и цифр)
```

Сохраните ссылку и пароль. Показать их снова в любой момент:
```bash
sudo bash /opt/entropy-green/install-green.sh --show-login
```

Вместо ручного ввода кошельков можно подготовить файл `wallets.txt` — по строке на кошелёк:
`адрес ключ_агента`:
```bash
sudo bash install-green.sh --wallets-file ~/wallets.txt
shred -u ~/wallets.txt
```
Файл с ключами не кладите в папку архива и удалите сразу после установки.

## 5. Панель по ссылке

1. Откройте ссылку из раздела 4 в браузере (Chrome, Firefox, Safari).
2. Браузер предупредит: «подключение не защищено» / «сертификат не доверенный». Это нормально:
   сертификат создан на вашем сервере, а не куплен. Нажмите «Дополнительно» → «Перейти на сайт».
   Если хотите убедиться, что это ваш сервер, сравните отпечаток сертификата (значок замка →
   сертификат → SHA-256) с тем, что напечатал `--show-login`.
3. Введите логин `admin` и пароль.

После 5 неверных паролей подряд вход с вашего адреса блокируется на 15 минут. Забыли пароль —
задайте новый (прежний сразу перестанет действовать):
```bash
sudo bash /opt/entropy-green/install-green.sh --reset-password
```

По-прежнему можно открыть панель через SSH-туннель: `ssh -L 8765:127.0.0.1:8765 user@IP_СЕРВЕРА`,
затем в браузере `http://127.0.0.1:8765`.

### Настройки ПК (раздел панели)

- **Номер ПК и окна входа** — их назначает сервер настроек; вручную менять не нужно. Новые окна
  от сервера применяются сами, когда у бота нет открытых позиций.
- **Входы по рынкам** — галочки «рынок × направление». Снятая галочка запрещает новые входы в этом
  направлении; открытые позиции продолжают вестись до выхода. Нажмите «Применить».
- Если сейчас открыты позиции и вы что-то выключили, **все новые входы сразу приостанавливаются**
  (файл `state/entry-hold.json`; выходы и их настройки не меняются), а сами настройки применяются
  после закрытия позиций — тогда входы возобновятся. Галочка «Можно перезапустить бота с
  открытыми позициями» разрешает применить сразу (позиции при перезапуске не закрываются).

## 6. Включение и выключение торговли

**В панели:** «Настройки ПК» → поставьте галочку «Реальная торговля включена» → «Применить» →
напишите `ДА`. Бот запустится; пока он не подтвердит работу, новые входы не открываются.
Если бот не подтвердил работу, но уже запущен, торговля остаётся включённой с запретом новых входов
(панель пишет «Торговля включена, новые входы заблокированы») — повторите включение или выключите
торговлю.

**Выключить:** снимите галочку и нажмите «Применить». Бот остановится, когда не останется открытых
позиций; до этого новые входы приостановлены, а позиции доводятся до выхода.

Из терминала (то же самое):
```bash
sudo bash /opt/entropy-green/install-green.sh --live
```

## 7. Проверка работы

```bash
sudo bash /opt/entropy-green/install-green.sh --status   # версия, службы и журнал
sudo journalctl -u entropy-green -f                      # журнал бота в реальном времени
```

## 8. Обновление

**Кнопкой.** В панели откройте «Обновления» → «Проверить обновления». Если есть новая версия, появятся
её номер и описание — нажмите «Обновить». Дальше всё происходит само:
1. новая версия скачивается с канала обновлений владельца бота;
2. проверяются цифровая подпись владельца и контрольная сумма — чужой или повреждённый архив не ставится;
3. новая версия проверяет себя и ваши настройки, пока старая продолжает работать;
4. бот ставит паузу новых входов (выходы работают) и ждёт, пока каждый кошелёк подтвердит её и
   закончит текущую сделку; если подтверждения нет за 2 минуты, обновление откладывается, бот не
   останавливается;
5. работающая версия записывает список открытых позиций, затем бот и панель перезапускаются на новой;
   открытые позиции **не закрываются** (`FLATTEN_ON_SHUTDOWN=false` обязателен — иначе обновление
   откажется);
6. новая версия должна показать каждую позицию из списка (или запись о её закрытии), а панель по
   ссылке — открыться; если этого нет или бот не заработал за несколько минут, автоматически
   возвращается прежняя версия, а неудачная больше не ставится. Пауза входов снимается в любом исходе.
   Ключи кошельков при обновлении не меняются.

**Из терминала** — то же самое:
```bash
sudo bash /opt/entropy-green/install-green.sh --update-check   # только проверить
sudo bash /opt/entropy-green/install-green.sh --update-now     # проверить и установить
```

**Переход с версии 1.0.1** (ПК ставился с номером `--pcs M --pc N`) — только кнопкой или
`--update-now`: новая версия сама зарегистрирует ПК, запишет новые настройки (все рынки, секунды от
сервера) и создаст панель по ссылке. После обновления выполните один раз:
```bash
sudo bash /opt/entropy-green/install-green.sh --show-login
```
Если канал обновлений ещё не задан:
`sudo bash /opt/entropy-green/install-green.sh --set-channel http://168.144.242.18:8080`.

Журнал обновлений: `/var/log/entropy-green-update.log`, применения настроек —
`/var/log/entropy-green-settings.log` (ключей не содержат).

## 9. Удаление

```bash
sudo bash /opt/entropy-green/install-green.sh --uninstall
```
Копия `.env` и `state/` сохранится в `/root/entropy-green-backup-*`. Номер ПК сохраняется: после
повторной установки сервер выдаст тот же. Удалить и его: `--purge` вместо `--uninstall`.
Перед удалением проверьте в интерфейсе Hyperliquid, что открытых позиций нет.

## 10. Если что-то не так

| Проблема | Что сделать |
|---|---|
| Браузер: «подключение не защищено», «сертификат не доверенный» | Это нормально для своей панели — «Дополнительно» → «Перейти на сайт» (раздел 5) |
| Ссылка не открывается | `sudo bash /opt/entropy-green/install-green.sh --show-login` — проверит и починит панель; в облаке откройте входящий порт 8443/TCP в настройках сети сервера |
| «Неверный логин или пароль» | Логин `admin`; пароль — `--show-login`. После 5 ошибок подождите 15 минут или `--reset-password` |
| «сервер настроек не ответил — резервные окна» | Ничего делать не нужно: ПК торгует в резервных секундах и сам повторит регистрацию |
| Панель: «Ваш запрос ждёт применения» | Открыты позиции: настройки применятся после их закрытия (или поставьте галочку «Можно перезапустить…») |
| Панель: «нужна помощь владельца» | Бот продолжает вести позиции, новые входы удерживаются. Пришлите владельцу `/var/log/entropy-green-settings.log`; после проверки: `sudo bash /opt/entropy-green/install-green.sh --settings-resolve` (удержание входов снимает `--settings-resolve --release-hold`) |
| «архив собран для …, а сервер …» | Нужен архив для архитектуры вашего сервера — попросите у владельца бота |
| «контрольные суммы не совпали» | Архив повреждён — скачайте заново |
| «этот ПК (номер из 1.0.1) переходит на автонастройку только через канал» | `sudo bash /opt/entropy-green/install-green.sh --update-now` (раздел 8) |
| «установка прервана — /opt/entropy-green удалён» | Исправьте причину из сообщения выше и повторите `sudo bash install-green.sh` |
| «проверка настроек не прошла» | Проверьте адреса и ключи в `/opt/entropy-green/.env` (`sudo nano /opt/entropy-green/.env`), затем `sudo bash /opt/entropy-green/install-green.sh --reconfigure` |
| «Канал обновлений не настроен» | `sudo bash /opt/entropy-green/install-green.sh --set-channel http://168.144.242.18:8080` |
| «подпись манифеста не прошла проверку» | Ничего не установлено. Сообщите владельцу бота |
| «возвращена версия …» | Новая версия не заработала, работает прежняя. Пришлите владельцу `/var/log/entropy-green-update.log` |
| «уже устанавливалась или не прошла проверку» | Ждите следующую версию: неудачная версия повторно не ставится |
| «манифест канала устарел» | Владелец давно не переподписывал канал — сообщите ему |
| «установка не закреплена за root» | Распакуйте архив текущей версии и выполните `sudo bash install-green.sh --upgrade` |
| «systemd недоступен» | Контейнер или система без systemd: установка и проверка проходят, службы не запускаются |
| Служба перезапускается | `sudo journalctl -u entropy-green -n 100` — пришлите вывод владельцу бота (ключей в нём нет) |
| Время сервера неточное | `timedatectl` — должно быть `System clock synchronized: yes` |

Журнал установки: `/var/log/entropy-green-install.log` (ключей и пароля панели не содержит).

## Безопасность

- Никогда не передавайте никому файл `.env` и ключи агентов. Резервные копии в
  `/root/entropy-green-backup-*` тоже содержат `.env` — храните их так же.
- Ключ агента может торговать, но не может выводить средства; при утечке удалите агента на
  https://app.hyperliquid.xyz/API и создайте новый.
- Панель по ссылке открыта из интернета (порт 8443) и защищена паролем, шифрованием (HTTPS) и
  блокировкой после неудачных попыток. Её обслуживает отдельный системный пользователь `entropy-gw`,
  который не может прочитать ключи и файлы бота. Ключи и адреса кошельков панель не показывает.
  Пароль хранится только на сервере: `/etc/entropy-green/dashboard-login` (доступ только root).
- Серверу настроек владельца отправляются только: случайный номер установки, отпечаток сервера,
  версия, включена ли торговля, число кошельков, оборот, число сделок и аварийных закрытий за день.
  Ключи, адреса кошельков и содержимое `.env` не отправляются никогда.
- Раз в минуту бот отправляет на мониторинг владельца счётчики без адресов кошельков и ключей (версия, оборот, стоимость, число сделок и сбоев); сервер видит IP установки.
- Установщик не пишет ключи в журнал и не передаёт их в параметры команд. Программа работает от
  пользователя `entropy`; обновление ставится только с подписью владельца бота; программа, ссылки и
  ключ канала принадлежат root, и бот не может их подменить.
- Держите на кошельках только сумму, которую готовы использовать в торговле.
